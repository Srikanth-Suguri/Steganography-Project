# Steganography Project in C

## Description
This project implements image steganography using the C programming language. It hides secret text messages inside BMP images and allows users to retrieve the hidden messages without visibly changing the image.

The project uses Least Significant Bit (LSB) encoding to embed secret data into image pixels.

## Features
- Encode secret text into a BMP image.
- Decode hidden text from a stego image.
- Hide messages using LSB steganography.
- Validate command-line arguments.
- Check image capacity before encoding.
- Handle file operations and errors.
- Store the encoded output in a new image file.

## Technologies Used
- C Programming
- Structures
- Pointers
- Arrays and Strings
- File Handling
- Dynamic Memory Allocation
- Bitwise Operations
- LSB Steganography

## Project Files
- `main.c` – Handles command-line arguments and selects encoding or decoding.
- `encode.c` – Implements the encoding process.
- `encode.h` – Contains encoding function declarations and structures.
- `decode.c` – Implements the decoding process.
- `decode.h` – Contains decoding function declarations.
- `common.h` – Contains common definitions used by the project.
- `types.h` – Defines project data types and status values.

## Compilation
Compile the project using GCC:

```bash
gcc *.c 
```

## Usage

### Encode a Secret Message

```bash
./a.out -e beautiful.bmp secret.txt
```

This command hides the contents of `secret.txt` inside `beautiful.bmp`.

### Decode a Secret Message

Use the stego image generated by your encoding program:

```bash
./a.out -d stego.bmp
```

The decoded message is saved according to the output behavior implemented in the program.
